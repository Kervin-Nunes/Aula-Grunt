# Aula Grunt — Automação de Tarefas ⚙️

Repositório de estudo sobre o uso do **Grunt** como task runner no desenvolvimento front-end. O projeto demonstra a configuração e uso de tarefas automatizadas para otimização do fluxo de trabalho.

## 🛠 Tecnologias utilizadas

- JavaScript
- Grunt (task runner)
- Less (pré-processador CSS)

## ⚡ Tarefas automatizadas

- Compilação de **Less** → CSS
- Minificação de **JavaScript** (geração do `.min.js`)
- Watch de arquivos para recompilação automática

## 🚀 Como rodar

```bash
npm install
npx grunt
```

## 💡 Objetivo

Aprender a configurar pipelines de build front-end com Grunt, entendendo o papel dos task runners no desenvolvimento moderno.
